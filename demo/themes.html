Themes

Style annotations using CSS custom properties. Set theme: 'name' in options to add a data-theme attribute, then target it in CSS to override variables. Multiple themes can coexist on the same page.

Default

No theme option — uses the built-in variable defaults.

Dark

theme: 'dark' — dark tooltips, blue-tinted annotation areas, rounded corners, shadows.

.image-annotate-canvas[data-theme="dark"] {
  --image-annotate-canvas-border: 1px solid #333;
  --image-annotate-area-border: rgba(255, 255, 255, 0.7);
  --image-annotate-area-inner-border: rgba(255, 255, 255, 0.3);
  --image-annotate-area-bg: rgba(100, 149, 237, 0.15);
  --image-annotate-area-radius: 3px;
  --image-annotate-hover-color: #6ea8fe;
  --image-annotate-hover-editable-color: #6ea8fe;
  --image-annotate-hover-bg: rgba(100, 149, 237, 0.25);
  --image-annotate-note-bg: #2a2a3e;
  --image-annotate-note-border: #4a4a6a;
  --image-annotate-note-text: #e0e0f0;
  --image-annotate-note-radius: 4px;
  --image-annotate-note-shadow: 0 2px 8px rgba(0, 0, 0, 0.4);
  --image-annotate-edit-bg: #1e1e2e;
  --image-annotate-edit-border: #4a4a6a;
  --image-annotate-edit-radius: 6px;
  --image-annotate-edit-shadow: 0 4px 12px rgba(0, 0, 0, 0.5);
  --image-annotate-button-bg: #2a2a3e;
  --image-annotate-button-bg-hover: #3a3a5e;
  --image-annotate-button-border: #4a4a6a;
  --image-annotate-button-text: #e0e0f0;
}

Minimal
